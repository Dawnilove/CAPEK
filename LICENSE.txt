1. 허용
   - 개인 학습, 교육, 연구 목적으로 CAPEK을 무료로 설치하고 사용할 수 있다.
   - 사용자가 만든 로봇 설정, 학습 기록, 학습된 두뇌 파일은 사용자의 것이다.

2. 금지
   - 프로그램을 수정, 역컴파일, 역공학, 분해하는 것.
   - 프로그램을 다른 사람에게 재배포하거나 판매하는 것. 배포 저장소의 링크를 공유하는 것은 허용한다.
   - 회사 업무, 유료 서비스, 수익을 내는 활동에 쓰는 것(상업적 사용). 필요하면 저작권자에게 먼저 허락을 받는다.

3. 보증 없음
   - 프로그램은 "있는 그대로" 제공한다. 특정 목적에 맞는다는 보증도, 오류가 없다는 보증도 없다.
   - 프로그램을 쓰다 생긴 손해에 대해 저작권자는 책임지지 않는다.

4. 외부 서비스
   - AI 조언 기능은 사용자가 입력한 본인의 Anthropic API 키로 동작한다. 호출 비용은 사용자의 계정에 청구된다.
   - 이 기능을 쓰면 학습 설정과 지표 요약이 Anthropic으로 전송된다. 파일 경로와 API 키는 전송하지 않는다.

5. 제3자 소프트웨어
   - CAPEK은 MuJoCo, PyTorch, Stable-Baselines3, PyQt6 등 오픈소스 소프트웨어를 포함한다. 각 소프트웨어는 자신의 라이선스를 따른다.
